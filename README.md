# 協和醫學堂徵信錄序（哈佛燕京圖書館 DRS 430993133，1910）

*Xie he yi xue tang zheng xin lu [Preface to the Union Medical College Report]*

1910 年上海美華書館排印的《協和醫學堂徵信錄》序文，記北京協和醫學堂倡設、開學、捐助和醫學生培養。哈佛燕京圖書館藏本 DRS 430993133，原印題作「協」，館目作「恊」。書內所記學堂、慈善會、教員與捐助可用於研究清末醫學教育與跨國慈善。

本版收入原編一至三面完整〈序〉，合計 26 欄。提供 JSON、逐欄與連讀 TXT、TEI P5，以及該 PDF 第 7–9 頁逐欄定位。兩份 AI 影像稿比對並回圖處理，保留原刻圓句點。尚無人類全文雙校、專家審定或準確率量測。
